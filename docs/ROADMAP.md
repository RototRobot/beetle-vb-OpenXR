# Project direction

Our next release priorities are portable Windows packaging, complete dependency
notices, and clear installation instructions. Broader headset, runtime, and game
coverage will guide compatibility improvements.

Potential additions include automatic cover lookup, richer library organization,
and a headset-view desktop mirror. Standalone headset and other operating-system
ports require separate graphics and platform backends.

For available features and usage, see the [README](../README.md).
